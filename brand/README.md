# Neptune brand

- `icon-1024.png` — the icon: a flat blue planet with one solid ring, on transparency (no tile). The same planet is the app icon, the taskbar and tray icon, the website favicon and the web app icons. Drawn by `scripts/render-icons.js`, which writes every size in `src-tauri/icons/`; the website's `favicon.png` (128), `img/icon-256.png` and `img/icon-1024.png` are copies of `128x128.png`, `128x128@2x.png` and `icon.png`.
- The Store box art and poster (`store/`) keep a night background on purpose: those are full-bleed artwork, not icons.

Colours: the night `#111115`, planet blue `#2f5fe0`, ring and accents `#7fa2ff`.
Older icon sets (the night tile, the blue pebble, the three-bar mark) are in Git history.
